# Incremental roadmap

V1 ships the local dashboard and assistant-driven operating contract. These are future increments, not claims of existing integrations.

1. **Reliable refresh adapters:** bounded authorized LMS/calendar reads, precise coverage, failure recovery and unattended-run diagnostics.
2. **Configurable routines:** wake/sleep window, refresh time, recurring personal events, workload budget and calendar-provider abstraction.
3. **Career workspace:** verified profile inputs, target markets, role matching, candidate deduplication and user-reviewed outreach drafts.
4. **Email action triage:** explicitly selected account, bounded threads, extracted deadlines, local reply drafts, no automatic sends.
5. **Progress and review:** explicit local-progress import, effort calibration, weekly review trends and approved-action reconciliation.

Open an issue when starting an increment. Split implementation into a focused PR with synthetic fixtures and acceptance tests. Avoid accumulating speculative issues or creating a separate project board until the backlog needs one.
